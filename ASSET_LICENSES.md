# Asset Licensing

The Apache-2.0 license covers source code in this repository unless a file states otherwise.

The repository intentionally excludes personal team photographs, production screenshots, report exports, and user-submitted media. The team page uses generated initials so a fork does not redistribute photography with undocumented rights.

Third-party fonts are fetched and self-hosted at build time through `next/font` under their respective upstream licenses. Package-specific licenses remain in the dependency packages and lockfile metadata.

Fork operators are responsible for rights to any photographs, icons, copy, or media they add. Do not add user-submitted evidence or allegation screenshots to Git history.
